What the numbers mean

cycles per iteration = elapsed core cycles / iterations
raw instructions per iteration = raw minstret delta / iterations
raw CPI = elapsed core cycles / raw minstret delta
CoreMark/MHz engineering estimate = iterations × 1,000,000 / cycles

Raw instruction-derived values require a clear qualification label. A modeled 100 MHz clock sets simulated target time; host simulator wall time does not measure the processor's performance. The simulated clock is also not an achieved silicon frequency.

A short run is an engineering run.

Published CoreMark requires its prescribed validation and at least 10 seconds of target execution. At modeled 100 MHz that requires one billion measured cycles. A short CRC-valid run is useful evidence, but it cannot be relabeled as a compliant score.

Evidence progresses through distinct stages

1

Compile firmware. Record toolchain, flags, source revisions/hashes, map, disassembly and static memory use.

2

Compile and elaborate the SoC TB. Verify that the new top and original design sources agree, without substituting design blocks.

3

Run firmware on the SoC. Preserve the watchdog outcome, trap details, bus failures, console, raw result block and command history.

4

Validate the workload. Require benchmark CRC / final-state checks and a consistent result header. A simulator exit alone cannot establish success.

5

Interpret performance. Retain source/tool/configuration identity and counter limitations. Signoff and published-score requirements need their own evidence.
