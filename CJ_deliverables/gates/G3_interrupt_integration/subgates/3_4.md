# CJ subgate 3.4: PLIC and CLIC disposition

**Official workbook status:** Blank (cell empty) (sheet G3, supplied workbook).

## Testbench, evidence and remaining work

CJ architecture direction: neither a PLIC nor a CLIC is used. Interrupt sources use the direct core IRQ interface, chosen for speed and simplicity over richer runtime reconfigurability. That is an architecture rationale, not a measured latency or frequency advantage. The implemented path is a 13-channel gateway plus a three-class arbiter inside the core. `Verification/irq_unit/tb_irq_restructure.sv` supplies controller/unit-level evidence, not SoC E2E evidence. Record this as the architecture disposition and obtain checklist acceptance if the workbook requires a formal waiver/approval. The supplied workbook cell remains blank; this record does not assert approval.
