\section{Coverage Summary}

The testbench contains 14 testcases (TC1--TC14) with a total of 28 individual pass/fail checks.
All 28 checks passed in the final Xcelium run. The testcases provide coverage across the following
functional areas:

\begin{itemize}[leftmargin=2em]
  \item Reset behavior and default state
  \item APB register accessibility
  \item Standard and Quad SPI write/read operations
  \item Multi-phase transactions (CMD + ADDR + DUMMY + DATA)
  \item TX FIFO burst operation
  \item Multi-word RX transfers
  \item Chip-select multiplexing
  \item Software reset
  \item EOT timing characteristics
  \item Interrupt safety
\end{itemize}
