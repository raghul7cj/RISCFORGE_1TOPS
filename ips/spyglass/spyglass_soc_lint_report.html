4. Detailed Analysis of Significant Findings

4.1 RV32M Hardware Multiplier Port Width Truncations (Rule W110 — 33 Violations)

Inside ips/riscv_core/rtl/rv32m_mul.v, the Booth Radix-4 multiplier instantiates 17 partial product generators (pp_gen) and 16 carry-save adder (csa) stages.

  • Booth PP Generators: u_ppg instances connect formal 6-bit port shift[5:0] to literal indices 2*i (actual width 2 to 5 bits). Verilog implicitly zero-extends, but SpyGlass flags this as width incompatibility.
  • CSA Carry Tree: The CSA module declares output [65:0] co (66 bits), but the parent wire is declared as [64:0] (65 bits). Bit 65 of carry-out is dropped.
// Example from rv32m_mul.v:
genvar i;
generate
  for (i = 0; i < 17; i = i + 1) begin: gen_booth
    // shift port is 6 bits wide; (2*i) evaluates to literal 2..5 bit integer:
    pp_gen u_ppg (.a(a_reg), .booth_code(booth_code[i]), .shift(2*i), .pp(pp[i]));
  end
endgenerate

4.2 Inferred Latch in Bootloader (Rule InferLatch — 1 Violation)

In ips/bootloader/bootloader.sv:476, the signal warm_boot_q is assigned in an incomplete procedural block without full assignment across all branch paths, causing SpyGlass to infer an asynchronous transparent latch. 

// bootloader.sv:476
// warm_boot_q is not assigned in all branches of the state machine, resulting in:
Latch inferred for signal 'warm_boot_q' in module 'bootloader'

4.3 Large Memory Array Declarations (Rule SYNTH_5273 & W123)

In sram_sp.sv and Instruction_Memory.v, behavioral memories (32 KB = 8,192 words × 32 bits = 262,144 bits) exceed the default static lint threshold (mthresh = 4096). For production ASIC flows, these behavioral arrays are mapped to compiled Foundry SRAM macros (SRAM BBox).
