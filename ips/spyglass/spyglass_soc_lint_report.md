## 3. Deep-Dive on Specific Violations

### 3.1 Booth Multiplier CSA Tree Widths (`W110` — 33 Violations)
* **File**: `ips/riscv_core/rtl/rv32m_mul.v`
* **Mechanism**:
  1. `u_ppg`: Formal port `shift` is declared as 6 bits wide in `pp_gen.v`, but instance connects `2*i` which resolves to literal integer (2 to 5 bits).
  2. `u_l1_0` to `u_l6`: Formal port `co` is declared as 66 bits in `csa.v` (`output [65:0] co`), but the connecting carry wires in `rv32m_mul.v` are declared as 65 bits (`[64:0]`).

### 3.2 Inferred Latch in Bootloader (`InferLatch` — 1 Violation)
* **File**: `ips/bootloader/bootloader.sv:476`
* **Mechanism**: `warm_boot_q` is assigned conditionally in an FSM block without complete fallback assignment across all state branches, causing SpyGlass to infer a latch.

### 3.3 Behavioral SRAM Array Thresholds (`SYNTH_5273`, `W123`)
* **Files**: `ips/RTL_SOC/sram_sp.sv` & `ips/instr_module/Instruction_Memory.v`
* **Mechanism**: Large behavioral arrays (32 KB = 262,144 bits) exceed the default static tool limit (`mthresh = 4096`). In synthesis/ASIC flows, these are mapped to Foundry SRAM macro blackboxes.
