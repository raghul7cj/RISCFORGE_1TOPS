## Objective

Perform deep structural analysis of the SoC clock and reset topology, async crossing points, and connectivity gaps **before** synthesis. This catches CDC (Clock Domain Crossing), RDC (Reset Domain Crossing), and glitch risks that synthesis tools won't flag but that cause unpredictable FPGA behaviour.

> [!IMPORTANT]
> The SoC has **5 active reset domains** (RevB Table 3.1). All must be verified as properly synchronized. A 6th domain (AON watchdog) is **specified but unconnected** (D-169, D-180).

### 2.3 — Clock Domain Inventory

The SoC is **intended to be single-clock** (`clk_i`). Verify no unintended secondary clocks exist.

| Signal | Role | Driven By | Status |
|:-------|:-----|:----------|:------:|
| `clk_i` | Primary SoC clock | External input | ⬜ |
| `spi_clk_o` | SPI SCK output | `spi_master_clkgen.sv` (divider) | ⬜ |
| `clk_aon_i` | AON timer clock | **NOT CONNECTED** (D-169) | 🔴 |
| I2C SCL | I2C serial clock | Generated by I2C master (`PRE` register) | ⬜ |

> [!WARNING]
> `spi_clk_o` is a **generated clock** from a divider. Vivado will require an explicit `create_generated_clock` constraint in Stage 5 to avoid false paths and timing analysis errors.

### 2.5 — Unconnected Output Check (Potential X-propagation)
