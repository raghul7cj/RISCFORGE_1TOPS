Architectural gap surfaced by this figure set

The CLIC IP is fully implemented in the repository but is not instantiated by riscforge_soc_subsystem: the sixth APB slot is documented as replacing it and ext_irq_i/sw_irq_i are tied to 0. What is actually live is an in-core irq_gateway + irq_arbiter with no claim mechanism. fig15 and fig16 draw both, marking the CLIC side as intended rather than present.

8RV32 Core

Quality gate. All figures are produced by the shared kernel _figstyle.py; each d_*.py script is standalone and idempotent. Re-run any of them with py -3 d_<topic>.py from this directory. Every script calls qa_report(), which machine-checks text/text overlap, text/wire collision, text escaping its box, canvas clipping and grouping-brace collisions — all 18 report clean. Each figure was additionally reviewed by eye as a rendered image and refined; defects fixed in that pass included wire-label pills wider than the gap they sat in, titles and footers overhanging the frame, badges half-outside their cells, healthy states painted in fault colours, and grouping braces slicing through labels.
