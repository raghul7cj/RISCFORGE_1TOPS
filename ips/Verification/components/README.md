# Component Evidence Records

These records summarize retained execution evidence for the blocks scoped by RISCFORGE_Verification_Plan_RevB.docx. The master plan remains the source for requirements, test scenarios, check IDs, and sign-off criteria. This directory records what existing runs actually demonstrate.

Every record names its test boundary, run, logs or snapshots, result, and limitation. A run summary is not promoted to a master-plan sign-off until its test cases are traced to the applicable check IDs and the required configuration.

## Record template

Use component_evidence_template.md when adding a record. Keep the report concise and link to original run artifacts instead of moving or editing them. Record exact test-case mappings only after checking the bench and run evidence.
