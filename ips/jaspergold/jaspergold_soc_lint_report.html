4. Violation Breakdown & Recommended Action Plan

Structural Issue #1: Combinational Reset (RST_IS_DCMB)
Location: riscforge_soc_subsystem.sv:469
Action: Replace direct combinational assign with a standard reset synchronizer instance (2-FF chain clocked by clk_i). Ensures glitch immunity during power-up and warm boot transitions.
Coding Style Issue #2: Top-Level Output Reads (OTP_NR_READ)
Location: riscforge_soc_subsystem.sv:708, 1131-1135
Action: Declare internal wires for peripheral interrupt lines (e.g. uart_int_s) and drive both the core CLIC and the top-level output port assign uart_int_o = uart_int_s;.
DFT / IO Issue #3: Unregistered Primary Outputs (OTP_NO_RGTM)
Location: Peripheral I/O ports (UART, SPI, I2C, GPIO)
Action: Register peripheral outputs at top-level boundary or verify pad-to-pad IO timing constraints in Cadence Innovus / Synopsys PrimeTime.
