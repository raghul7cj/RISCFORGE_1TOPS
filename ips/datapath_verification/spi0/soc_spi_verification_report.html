1. Executive Summary

This report documents the successful end-to-end integration and simulation sign-off of the APB SPI Master IP (apb_spi_master @ 0x4000_4000) integrated within the complete RISCFORGE 1TOPS SoC Subsystem (riscforge_soc_subsystem.sv). The verification suite validated bidirectional SPI communications across the 5-stage RV32IM processor datapath interacting with the official Infineon S25FS512S QSPI Vendor Flash Model (s25fs512s.sv), with real-time test execution streamed over the 16550 UART0 peripheral.

SoC & Core Architecture

  • Core: RV32IM 5-stage RISC-V with HW Multiplier/Divider
  • Memory: 32 KB ISRAM (0x0001_0000) + 32 KB DSRAM (0x0002_0000)
  • Interconnect: AXI-Lite Crossbar ($2\text{S} \times 3\text{M}$) + AXI-to-APB Bridge
  • Boot Scheme: Warm Boot with zero-cycle fast SRAM retention

SPI & Peripheral Features

  • SPI Master IP: Full APB register interface @ 0x4000_4000
  • Flash Device: Infineon S25FS512S (512 Mbit / 64 MB NOR Flash)
  • Opcodes Tested: 0x9F (ID), 0x06 (WREN), 0x05 (RDSR), 0x02 (PP), 0x03 (Read), 0x0B (Fast Read)
  • Telemetry: Live 16550 UART0 logging @ 0x4000_2000

System Memory Map Table

Memory Region Base Address Size Interconnect Route Role & Access Type

ISRAM 0x0001_0000 32 KB Fetch Mux / AXI Priv-Write Instruction RAM (holds compiled .text)
DSRAM 0x0002_0000 32 KB Direct LSU / AXI Bridge Data RAM (Stack @ 0x28000, .data, .rodata)
UART0 0x4000_2000 4 KB AXI Crossbar → APB[2] 16550 UART console logging interface
SPI Master 0x4000_4000 4 KB AXI Crossbar → APB[4] SPI Master Controller registers & FIFOs

3. Software Toolchain & Image Generation Flow

Bare-metal C code is cross-compiled using the GNU RISC-V toolchain, linked with a customized linker script, and translated by a standalone Python converter into word-addressed memory hex images.
