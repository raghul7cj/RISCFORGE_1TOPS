1. Executive Summary

This report documents the architectural design, software-to-hardware toolchain pipeline, peripheral register map, and verification methodology for the RISCFORGE 1TOPS SoC Subsystem. The complete end-to-end flow was validated on the Synopsys VCS simulation environment by executing bare-metal software loaded directly into internal SRAM memories and streaming live verification output across the 16550-compatible APB UART (UART0) peripheral.

Core Subsystem Features
  • RV32IM 5-stage pipelined RISC-V processor.
  • Split Harvard native interfaces (ISRAM & DSRAM).
  • Low-latency hybrid memory router (direct SRAM / AXI MMIO).
  • Dual-mode hardware bootloader (SPI flash / warm bypass).
Interconnect & Peripherals
  • AXI-Lite Crossbar (2 Masters × 3 Slaves).
  • AXI-Lite to APB Bridge (6 peripheral slots).
  • 16550 APB UART with programmable baud rate.
  • Integrated APB Timers, I2C, SPI, and lowRISC GPIO.

2. SoC Subsystem Architecture

The system architecture separates high-bandwidth instruction and data SRAM accesses from peripheral memory-mapped I/O. Instruction fetches and stack/data memory accesses bypass the bus fabric for zero-wait-state performance, while accesses to addresses 0x4000_0000 and above are dynamically routed over the AXI-Lite Crossbar to the APB bridge.

3. UART0 16550 Register Map & Control/Status Registers (CSR)

The UART peripheral (apb_uart.sv / obi_uart.sv) is located in APB Slot 2 at base address 0x4000_2000. It adheres to the industry-standard 16550A UART specification. The peripheral uses a 3-bit word address offset extracted from PADDR[4:2]. Registers at offsets 0x00 and 0x04 are multiplexed via the DLAB bit (LCR[7]).

Byte Offset Register Name Width Access DLAB State Description / Functional Role
0x00 RBR (Receiver Buffer) 8-bit Read-Only DLAB = 0 Received character from top of RX FIFO.
0x00 THR (Transmit Holding) 8-bit Write-Only DLAB = 0 Character to push into TX FIFO for transmission.
0x00 DLL (Divisor Latch LSB) 8-bit Read / Write DLAB = 1 Baud rate divisor least significant byte.
0x04 IER (Interrupt Enable) 8-bit Read / Write DLAB = 0 Individual interrupt enable controls.
0x04 DLM (Divisor Latch MSB) 8-bit Read / Write DLAB = 1 Baud rate divisor most significant byte.
0x08 IIR (Interrupt ID) 8-bit Read-Only Any Identifies highest pending interrupt source.
0x08 FCR (FIFO Control) 8-bit Write-Only Any Enables and resets TX/RX FIFOs and trigger levels.
0x0C LCR (Line Control) 8-bit Read / Write Any Configures word length, stop bits, parity, and DLAB.
0x10 MCR (Modem Control) 8-bit Read / Write Any DTR, RTS, loopback mode, and general outputs.
0x14 LSR (Line Status) 8-bit Read-Only Any Transmitter & receiver status flags (THRE, TEMT, DR, ERR).
0x18 MSR (Modem Status) 8-bit Read-Only Any CTS, DSR, RI, CD carrier status and delta flags.
0x1C SCR (Scratchpad) 8-bit Read / Write Any General-purpose 8-bit scratch register.

Key UART Control & Status Register Bitfields

LCR — Line Control Register (0x0C)

[7] DLAB Divisor Latch Access Bit (1 = DLL/DLM, 0 = THR/RBR/IER)
[6] BREAK Set Break Control (force TX spacing)
[5] STKP Sticky Parity Selection
[4] EPS Even Parity Select (1 = Even, 0 = Odd)
[3] PEN Parity Enable
[2] STOP Stop Bits (0 = 1 stop bit, 1 = 2 stop bits)
[1:0] WLS Word Length (00=5b, 01=6b, 10=7b, 11=8b)

Standard 8N1: LCR = 0x03 | Baud Config: LCR = 0x83
LSR — Line Status Register (0x14)

[7] FIFO_ERR Error in Receiver FIFO
[6] TEMT Transmitter Empty (FIFO & Shift Reg empty)
[5] THRE TX Holding Register Empty (ready for next write)
[4] BI Break Interrupt detected
[3] FE Framing Error detected
[2] PE Parity Error detected
[1] OE Overrun Error (data lost)
[0] DR Data Ready (byte available in RBR)

Ready to Write: LSR & 0x20 != 0 | Idle Reset: 0x60
IER — Interrupt Enable Register (0x04)

[3] EDSSI Enable Modem Status Interrupt
[2] ELSI Enable Receiver Line Status Interrupt
[1] ETBEI Enable Transmitter Holding Register Empty IRQ
[0] ERBFI Enable Received Data Available Interrupt

Polling Mode: IER = 0x00 (all interrupts disabled)
FCR — FIFO Control Register (0x08)

[7:6] RX_TL RX FIFO Trigger Level (00=1B, 01=4B, 10=8B, 11=14B)
[2] TX_RST Transmitter FIFO Reset (self-clearing)
[1] RX_RST Receiver FIFO Reset (self-clearing)
[0] FIFO_EN FIFO Enable (1 = 16550 FIFOs, 0 = 16450 byte)

Standard Init: FCR = 0x07 (Enable & clear FIFOs)

5. Reset Sequence & Execution Flow

The SoC utilizes a dual-path reset architecture coordinated by bootloader.sv. To support rapid simulation with preloaded memories, the testbench issues a Warm Reset pulse, bypassing the hardware memory wipe while cleanly initializing core execution registers.

Cold Boot Sequence (Hardware Reset)

1. hard_rst_ni = 0 → 1 enters state S_CLEAR_SRAM.
2. Hardware loops 16,384 times writing 0x0 to ISRAM and DSRAM.
3. Bootloader initiates SPI flash read & streams payload into ISRAM.
4. Reasserts core_rst_n and releases core to runtime.

Warm Boot Sequence (Simulation Fast-Path)

1. hard_rst_ni = 1, pulse soft_rst_ni = 0 → 1.
2. Bypasses S_CLEAR_SRAM & SPI flash reading.
3. Traverses S_CLEAN_ASSERT → S_CLEAN_RELEASE → S_DONE in 6 cycles.
4. Preloaded imem.hex and dmem.hex are preserved completely intact.

6. UART0 Datapath Verification & Validation

The test program (uart_smoke_test.c) validates the processor datapath, compiler ABI compliance, and peripheral interconnect through the following execution steps:

  1. Reset Vector & Trampoline: Core emerges at 0x0000_0000 in BootROM, executes lui sp, 0x28000 (sets stack pointer to DSRAM top), and executes jal x0, 0x10000 to jump to _start in ISRAM.
  2. C Runtime Initialization (crt0.S): Clears all 31 general-purpose registers, sets global pointer gp, and zeroes the .bss section in DSRAM.
  3. 16550 UART Initialization (uart_min.h): Sets DLAB=1 in LCR (0x83), writes Divisor Latches (DLL=2, DLM=0 for 32 clocks/bit), clears DLAB=0 (0x03 for 8N1), disables interrupts (IER=0), and resets FIFOs (FCR=7).
  4. Banner Transmission: Streams the banner string from DSRAM .rodata to UART_THR (0x4000_2000) after polling Line Status Register (UART_LSR & THRE).
