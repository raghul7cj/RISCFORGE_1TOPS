3.4 · PLIC / CLIC

PLIC not used / CLIC not used

  • Done: CJ disposition: neither a PLIC nor a CLIC is used. The project direction favours a direct core IRQ interface for speed and simplicity over richer runtime reconfigurability; this is an architecture rationale, not a measured latency or frequency advantage. Interrupt sources use the direct core IRQ interface. The core accepts the interrupt in EX as a trap packet and commits it at WB. The 13-channel map is in the architecture page.
  • Now: Record and obtain acceptance of this direct-interface architecture disposition in signoff; the workbook cell is still blank and no approval is inferred.
