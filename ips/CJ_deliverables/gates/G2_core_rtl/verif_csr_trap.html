3. Trap-entry check architecture

Figure 1 shows where a commit scoreboard would watch. It takes the same WB packet that drives the controller and predicts the CSR state, the redirect target and the flush, then compares them with what the three consumers receive. No such scoreboard exists; the block is SPECIFIED as a proposal.

4. CSR write paths and priority

The MSIP storage bit is a separate process: a Port C write to mip or a Port B write to mip sets msip_r from bit 3 (csr_regfile.v:207-215). It does not follow the trap priority, so it can update in the same cycle as a trap.

5. CSR access-type matrix

All six instruction forms compute a new value from the old value and an operand (rs1 or the 5-bit immediate), then write through the mask below. csrrw(i): new = operand. csrrs(i): new = old | operand. csrrc(i): new = old & ~operand. The last column is the reach of immediate forms, which can only encode values 0 to 31.

Points to decide, each OPEN. (1) mstatus.MPP bits 11 and 12 are separately writable by software, and bit 1 is writable although no supervisor mode exists. (2) mtvec.MODE cannot be written, so the vectored branch of the controller (:98-101) is unreachable through the CSR instructions; vectored mode can be tested only by forcing mtvec. (3) Rev B 17.2 cites a misa reset value of 0x40001100 in the RISCOF ISA file, but the CSR file has no misa address and reads 0. (4) Writes to read-only or unimplemented addresses raise no trap in the source read. Whether each is intended is not recorded.

7. Assertion ideas

All are SPECIFIED candidates for CT-3 and need viability records.

IDProperty in words
S-1The cycle after trap_valid_i: mepc equals the packet PC, mstatus.MIE is 0 and MPP is 11.
S-2trap_valid_o and csr_write_en_mret_o are never high together.
S-3flush_pipeline_onehot_o equals 4'b1111 exactly when wb_trap_redirect_o is high.
S-4The MRET target has bits [1:0] equal to 0 and equals mepc[31:2] followed by 00.
S-5mintprio is unchanged across any trap or MRET cycle.
S-6A CSR write is never accepted in a cycle with trap_valid_i (instruction source dropped).
S-7At most one bit of clear_gateway_o is set, and none unless an interrupt commit occurs.
S-8mcycle increments by exactly 1 per clock when no write targets it.

8. Limits of this page

  • No CSR or trap test result has been produced against the current RTL as far as the repository shows.
  • Stale-testbench statements come from comparing source text with the current ports; the benches were not compiled.
  • Exception sources in the decode stage and the cause codes in memory_cycle.v were not read in full.
