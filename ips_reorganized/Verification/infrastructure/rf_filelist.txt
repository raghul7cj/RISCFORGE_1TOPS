# SINGLE SOURCE OF TRUTH for the compile list of the SoC-level testbench.
# Consumed by gen_filelists.py, which emits the tool-specific lists:
#
#   Verification/build/xsim/soc_verification.f   -> xvlog -f   (local Windows)
#                                                    also vcs -f / xrun -f
#   Verification/build/xsim/soc_verification.prj -> xelab -prj (Vivado IDE project)
#
# WHY THIS FILE EXISTS
# --------------------
# The two hand-written lists that used to drive this flow (RTL_SOC/soc_subsystem.f
# and Verification/infrastructure/soc_verification.f) were both authored against
# the REMOTE VLSI tree at /home/iiita/MALAY_SOC/rtl/, whose directory layout does
# not match this repository:
#
#   remote MALAY_SOC/rtl/          this repo (rtl/ips/)      remap
#   ------------------------       ---------------------     ---------------------------
#   RTL_SOC/rtl/<f>.sv             RTL_SOC/<f>.sv            drop the rtl/ level
#   SOC_FILES/include/apb          apb_uart-main/include/apb
#   SOC_FILES/include/obi          apb_uart-main/include/obi
#   SOC_FILES/include/common_cells apb_uart-main/include/common_cells
#   SOC_FILES/include/axi          apb_uart-main/include/axi
#   SOC_FILES/include/register_interface  *** ABSENT ***
#   uart/rtl/apb_uart.sv           apb_uart-main/rtl/apb_uart.sv
#   spi/spi_master/                spi_master_ip/spi_master/
#   apb_timer/apb_timer/           apb_timer-master/rtl/
#   apb_i2c-master/rtl/            apb_i2c-master/
#   axi_lite_to_apb/rtl/           axi_lite_to_apb/
#   bootloader/rtl/bootloader.sv   bootloader/bootloader.sv
#   axi_lite_xbar/                 axi_lite_xbar/            (unchanged)
#   riscv_core/rtl/                riscv_core/rtl/           (unchanged)
#   gpio-master/                   gpio-master/              (unchanged)
#   bus_monitors/                  bus_monitors/             (unchanged)
#   instr_module/                  instr_module/             (unchanged)
#
# That drift is the sole cause of the elaboration failures: every source path in
# the old lists resolved nowhere. Both remaps above and the dead-OBI-UART removal
# below are validated by a clean 85-file compile in AMD Vivado XSim 2022.2.
#
# The `include directives inside the IP sources name their containing directory
# (e.g. "apb/typedef.svh", "axi/assign.svh", "common_cells/registers.svh"), so
# BOTH the leaf directories and their PARENT must appear as INCDIR entries.
#
# ALL PATHS ARE RELATIVE TO THE REPOSITORY ROOT -- the directory that contains
# Verification/, RTL_SOC/, riscv_core/, axi_lite_xbar/, apb_uart-main/, ...
# (two levels above this file). gen_filelists.py resolves them to absolute paths
# before emitting, so the emitted lists behave identically under Windows XSim and
# Linux VCS/Xcelium regardless of the tool's working directory.
#
# DIRECTIVES
#   INCDIR  <path>       include search directory
#   SRC     <path>       required SystemVerilog source, in compile order
#   VSRC    <path>       required Verilog (non-SystemVerilog) source
#   OPT     <path>       optional source: compiled if present, skipped if absent
#   TOP     <name>       elaboration top module
#   DEFINE  <name>[=val] compile define passed to every tool
# =============================================================================

#   ERROR: [VRFC 10-2063] Module <prim_subreg>     not found  [gpio_reg_top.sv:1558]
