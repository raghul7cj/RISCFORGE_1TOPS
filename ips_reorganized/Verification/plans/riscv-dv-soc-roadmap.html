Architecture decisions before expansion

Direct ISR dispatch now; hardware vectoring is a separate decision

Current normal CSR writes cannot select mtvec.MODE=1. A software ISR dispatch table works with direct mode. Decide hardware-vectored support with the mentor by day 2; then verify its WARL, readback and vector-entry behavior.

Rev B and the current RTL describe different interrupt contracts

The local gateway now connects 13 sources. The current core uses software-managed mintprio nesting and has no automatic trap shadow stack. Reconcile the source map, classes, context-save contract, and existing predictor before counting evidence.

Accepted-interrupt replay cannot validate interrupt arbitration

Replay aligns CPU and ISS execution. An independent raw-source/pending/priority model must still detect a lost request or wrong winner. MMIO read replay also needs independent device checks before its response is used.

Verification closure and physical tapeout readiness have different evidence

Use the PDK delay to close functional requirements. Physical implementation, timing, equivalence, DFT, macro models, and foundry signoff remain later handoffs.

Evidence gates: G0/G1/G3 per run; G2/G4/G6 per candidate; G5 release input/decision at the frozen identity. Completing a scope level does not automatically satisfy Rev B.
