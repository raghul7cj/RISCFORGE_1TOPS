01Two linked verification goals

6.5 · Trigger and route

Real pin or timer event → peripheral IRQ → correct controller input. Check peripheral masks, mie, global MIE, thresholds and priority.

6.12 · Execute and return

Real event → accepted request → WB trap commit → ISR → MRET → correct resumed work. Add official-driver loopbacks and memory tests.

A controller input may carry several event reasons. An event can remain pending or coalesce; it does not always produce one committed interrupt.
