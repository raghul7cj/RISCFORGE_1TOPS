Read claims at the right evidence level

  1. Contract: intended behavior and exact approved scope, or an explicitly unresolved decision.
  2. Implementation: the source and selected configuration that implement the behavior.
  3. Check: stimulus, independent expectation and decisive observation.
  4. Evidence: identified run, checker verdict, logs and limitations.
  5. Disposition: what the requirement still needs; a merge or document is not gate approval.
