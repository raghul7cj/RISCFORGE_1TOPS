# F1 minimal ECALL/MRET smoke contract

Status: minimal smoke and reset-offset smoke PASS. Adjacent-store exception squash
FAILS on current RTL (F1-EXC-01). Do not interpret the smoke pass as complete precise
exception signoff. Diagram: [current architecture](docs/diagrams/core_trap_architecture.md).

## Scenario and independent expectation

The program configures direct mtvec through CSRRW, sets mstatus.MIE=1 through
software, and executes one ECALL. An independent machine-mode semantic extension
runs before reset release; expected PCs, CSR values, RF/store records and completion
counts come from the program image and architectural state, never observed trap data.
The ECALL is a trap commitment, not an ordinary retirement. MRET is a retirement.

Main instructions start at RESET_PC. The ECALL is at RESET_PC+0x1c. The handler is
at RESET_PC+0x100. It reads mepc/mcause/mstatus, stores those values to DMEM, adds
four to mepc, writes it back and executes MRET. Application execution resumes at
RESET_PC+0x20, writes completion signatures, reads restored mstatus and reaches a
checked terminal instruction. Fall-through RF/store poison after MRET is not part
of the expected stream. No force/deposit or direct DUT CSR/RF initialization is used.

| Checked value | Default independent expectation |
|---|---|
| Saved mepc on ECALL | 0x8000001c (exact ECALL instruction PC) |
| Cause | 11, synchronous M-mode ECALL |
| Direct handler PC | 0x80000100 |
| Entry mstatus | 0x00001880: MIE=0, MPIE=1, MPP=3 |
| Software-updated mepc and MRET target | 0x80000020 |
| Returned mstatus | 0x00001888: MIE=1, MPIE=1, MPP=3 |
| App DMEM words 0/1 | 0x5a / 2 |
| Handler DMEM words 2/3/4 | original fault PC / 11 / entry status |
| Handler poison DMEM word 5 | zero |

Expected counts are generated by semantic execution (23 retirements, 13 nonzero
GPR effects and five stores for the present image); those numbers are not encoded
as scoreboard limits. The offset smoke changes RESET_PC and relocates both handler
and expected PCs, exercising the same prediction/checking logic without edits.

The model supports the tested register forms of CSRRW and CSRRS for mstatus, mtvec,
mepc and mcause, plus earlier LUI/ADDI/SW/JAL semantics. It is not a complete privileged
ISA model. Direct mtvec only; MODE!=0 is rejected by this scoped model. MPP behavior
and CSR WARL masks follow the M-mode-only project contract in
[the Part 1 register contract](../tb_csr_lean/REGISTER_CONTRACT.md).
No CSR model is fed with observed DUT-computed operands or CSR read results.

## Temporal checks and squash accounting

Four new assert properties check ECALL packet/target and next-sample saved state,
and MRET packet/target and next-sample restored state. Concurrent sampling is
preponed: |=> checks the state at T+1 resulting from the commit edge T. PC target
checks use independent expected PCs, in addition to the existing pipeline monitor's
observed-target timing assertions. Entry/return sequence-cover witnesses are required
at completion. The smoke now activates M/W flush and WB redirect checks from F0.2.

All physical nonzero-GPR writes and accepted stores are checked independently of
retirement. The application instruction following ECALL is expected only AFTER the
handler and return; early replay cannot hide behind matching final memory. Every
configured SRAM word is checked against final independent state. Missing, duplicate,
extra or wrong effects fail. Completion requires one ECALL, one MRET, drained streams,
required witnesses and terminal retirement; the watchdog rejects halted execution.

The minimal smoke places a younger RF instruction immediately after ECALL and a
store next. This checks RF squash and EX-stage store squash. The separate dense
case swaps those two instructions, placing a store in MEM on the trap-commit edge.
It fails and is not excluded or classified as an intentional-negative test. The
initial first attempt used that dense layout and remains preserved; introducing a
complementary smoke is not a waiver or a relaxation of its expectation.

Default observed events: ECALL commits at 165 ns, MRET commits at 315 ns, post-return
stores occur at 375/395 ns and terminal completion is at 425 ns. These timestamps
describe this run, not hardcoded pass delays. Status/PC edge relationships are SVA.

## Evidence limits

The smoke is zero-wait, has IRQ inputs low and does not cover interrupts, vector
mode, illegal instructions, nested traps, load/store faults or trap/wait overlap.
F02-WB-01 remains open. Full trap signoff also requires resolving F1-EXC-01.
No RTL changes were made. Code coverage/report generation are not architectural proof.
